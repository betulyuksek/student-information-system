# 🎓 Student Information System

A console-based Student Information System developed using Python.

This project allows users to manage student records and grades through a menu-driven interface.

## ✨ Features

- Add new students
- Prevent duplicate student numbers
- List all students
- Search for students by student number
- Delete student records
- Update midterm and final grades
- Calculate individual student grade averages
- Calculate class average
- List successful students

## 🛠️ Technologies & Concepts

- Python
- Lists and Dictionaries
- Nested Dictionaries
- Functions and Parameters
- Loops and Conditional Statements
- Input Validation

## ▶️ How to Run

1. Clone this repository.
2. Open the project folder.
3. Run the following command:

```bash
python student_information_system.py
```
